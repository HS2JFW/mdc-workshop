# Triage Labels

The repository follows the canonical triage label vocabulary:

- `needs-triage`: Newly submitted issues awaiting review and classification
- `needs-info`: Requires more information or reproduction steps from the requester
- `ready-for-agent`: Confirmed specifications and actionable bug fixes ready for AI agents to implement
- `ready-for-human`: Architectural or UX decisions reserved for human review
- `wontfix`: Out-of-scope, invalid, or duplicate issues
